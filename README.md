# Lynie Kuan | Design Portfolio

Static site (HTML, CSS, JS). No build step.

## Publish on GitHub Pages
1. Create a repo (e.g. `lynie-portfolio`) and upload everything in this folder.
2. Repo **Settings > Pages** > Source: *Deploy from a branch* > `main` / `(root)` > Save.
3. Your site goes live at `https://<username>.github.io/<repo>/`.

## Edit
- Email and social links: top of `js/main.js`. The contact form opens the visitor's email app (opens a Gmail compose window).
- Add a design: put `name.webp` in `assets/img/full/` (about 1600px) and `assets/img/thumb/` (about 720px), then add one line to `work` or `faith` in `js/main.js`.
